# Screenshot Folder Guide

Put the README images for this project in this folder using the exact filenames below.

2. `02-route-finder.png`
3. `03-graph-visualization.png`

8. `08-analytics-dashboard.png`

## Recommended capture tips

- Use a desktop viewport so the dashboards have enough width.
- Capture each screen after the data fully loads.
- Favor the most informative state on each page:
  - a found route on Route Finder
  - a populated network on Graph Visualization
  - a rendered path on Live Map View
  - results visible on Algorithm Comparison
  - changed sliders or highlighted paths on Traffic Simulation
  - populated city and road lists on Manage Cities and Roads
  - charts and stat cards visible on Analytics Dashboard
- Crop out browser chrome if you want a cleaner README presentation.
